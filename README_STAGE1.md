## 关键概念

### 什么是 LLM 微调？

**预训练模型**：在大规模通用数据上训练的基础模型，具备广泛的语言理解能力。

**微调（Fine-tuning）**：在特定任务或领域的数据上继续训练预训练模型，使其适应特定场景。

### 为什么需要微调？

- 预训练模型是通用的，但可能不擅长特定领域
- 微调可以让模型学习特定风格、术语、知识
- 相比从头训练，微调成本低、效果好

### Qwen2.5-0.5B 模型

- **参数量**：5亿（0.5B）
- **特点**：中文友好、资源占用小、适合学习和实验
- **模型大小**：约 1GB
- **适用场景**：个人电脑、教学、快速原型
